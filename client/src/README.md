# GigFlow Dashboard

A full-stack lead management dashboard built using MERN Stack.

## Features

- JWT Authentication
- Lead Management CRUD APIs
- Search Leads
- Protected Routes
- Responsive Dashboard UI
- Backend Deployment on Render
- Frontend Deployment on Vercel

---

## Tech Stack

### Frontend
- React
- TypeScript
- Tailwind CSS
- Axios

### Backend
- Node.js
- Express.js
- MongoDB
- JWT Authentication
- TypeScript
